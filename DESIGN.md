## Links and navigation

Underline information and contact links at rest. Name the destination or action in the visible text. Use the same wording for repeat links to a guide. On hover, thicken the underline. On keyboard focus, show the shared focus ring.

Make each condition row a single link to the matching treatment heading. Keep the illustration on the left, underline the condition name and place a 20px right chevron at the far edge. Give a return link a left arrow and name the section it opens. Link directly to that section so the return also works for visitors arriving from search.

Use the filled button for booking. Phone, email and map links should say what they open. Keep the FAQ plus and minus symbols for expanding and collapsing answers.
